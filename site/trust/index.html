Accountability

Our honesty commitments

  • We label demo values as demo values, inside the generated brief itself, not just in a footnote.
  • We publish the full derivation: dataset, version, date fetched, interpolation method.
  • We never present output as stamped engineering; every brief names the licensed-engineer step.
  • We accept corrections like Wikipedia: fix a clause, merge a PR, everyone benefits.
  • The browser demo uploads nothing. The CLI needs no internet once installed.
FAQ

Questions reviewers actually ask

Is this a replacement for engineers or consultants?

No, and we refuse to pretend otherwise. OpenShelter produces the pre-design brief: hazard-appropriate systems, code-cited constraints, and compliance checks. A licensed local engineer performs the structural calculations and signs the drawings. Our aim is to make that engagement cheaper and better-informed, not optional.

Why are some hazard values still "demo"?

Flood and heat authority comes from national agencies, not from us inventing numbers. Rather than ship unlabeled guesses, we show clearly-marked placeholders and provide the plug-in interface (and funding roadmap) for agencies to contribute their own raster layers via pull request.

Who governs the code profiles? Could someone sabotage them?

Profiles are JSON files with citations, reviewed in pull requests, validated by CI, and intended to be co-owned by each country's standards community. Governance structure is documented in docs/GOVERNANCE.md; changes are traceable by git history like Wikipedia revisions.

How is this funded? What's the catch?

AGPL-3.0 means the tool is free forever; sustainability comes from paid localization contracts (a ministry commissions its own code profile and hosted instance), foundation grants (Sendai-aligned DRR funding), and dual licensing for commercial integrators. There is no user paywall and no data monetisation, see docs/FUNDING.md.

Can a government rely on this in procurement?

The briefs are designed to be attached to tender documents as requirements definitions, deterministic, version-stamped and citable. Procurement law differs by country; consult your legal team, but the audit trail (rule → hazard value → clause) is exactly what evaluation committees ask for.

Does it work without internet?

Yes. The Python CLI is stdlib-only and ships its grids as JSON; the browser demo caches everything on first load. Field teams routinely operate on prepaid connections, offline-first is a requirement, not a nicety.
