Newsroom

What changed, and when

A running log of releases, data upgrades and community milestones. Plain dates, no marketing gloss, because auditors and grant reviewers read changelogs.

2026-10-19Release

Site rebuilt as a multi-page experience

The single long scroll became eight focused pages with breadcrumbs, prev/next navigation and a standalone live-demo page. Same engine, clearer journey.

2026-10-12Data

Real hazard data wired in: USGS and NOAA

Earthquake scores now derive from the USGS ComCat catalogue (M6.0+, 1990-2026) and cyclone scores from NOAA IBTrACS climatology, both public domain. Every other layer stays clearly labelled as a demo placeholder until national agencies contribute authoritative grids.

2026-10-05Community

Code profiles are now community-owned

Adding a country means one JSON file and one pull request, scaffolded by a single command. Eurocode 8, IBC/ASCE 7, IS 139, NSCP and Sphere ship today; Bangladesh's BNBC is in review.

2026-09-28Release

v0.2: deterministic briefs, three formats

JSON for machines, Markdown for repositories, printable HTML for field teams. Byte-identical output for identical inputs, so a brief produced today can be cited verbatim in an audit next decade.

Roadmap

What's coming next

  • National flood & heat layers, contributed through pull requests by the agencies that own those numbers.
  • PDF export for briefs, the most-requested feature from pilot conversations.
  • Bengali, Spanish and French interfaces so municipalities can use the tool in their own language.
  • First pilot municipality, publishing a real reconstruction brief end-to-end.
