How OpenShelter works — and why you can trust every line

The problem in one paragraph

When disaster strikes, billions of dollars flow into emergency shelters every year. Most of those shelters are designed from copy-paste templates that ignore local building codes and local hazards — so the same "safe" shelter that survives an earthquake in one country collapses in a flood somewhere else. Hazard maps exist, building codes exist, but nothing free and auditable connects them.

The pipeline (three deterministic steps)
  1. Hazard fingerprint — your coordinates are looked up in gridded public-domain layers (USGS earthquake catalogue, NOAA cyclone climatology today; national flood & heat layers next). Every value is labelled with its source.
  2. Code profile — each jurisdiction's rules (Eurocode 8, IS 139, ASCE 7, NSCP, Sphere) live in a machine-readable JSON file that anyone can inspect, diff and correct via pull request.
  3. Rule engine — hazard × code produces ranked recommendations and compliance checks. The engine is deterministic: same inputs → byte-identical brief, forever. That is what makes it usable in audits and procurement.
Why "explainable" matters more than "smart"

A government spending public money must be able to answer: who decided this, on what basis? A neural network cannot cite clause 4.2 of a national standard. OpenShelter never guesses — every recommendation prints the hazard value and the code clause that produced it. No hidden model, no proprietary data, no vendor lock-in.

What it deliberately does NOT do

It does not replace a licensed structural engineer, it does not stamp drawings, and it does not claim site-specific geotechnical truth. It produces the pre-design brief that makes the engineer's job faster, cheaper and locally appropriate — closing the gap between "no plan at all" and "an unaffordable consultancy."

Who uses this, and what changes

🏛 Governments & disaster agencies

Turn shelter reconstruction budgets into code-compliant, auditable design requirements in minutes instead of months. Publish the briefs as open procurement documents.

🎓 Universities & schools

A real, forkable teaching tool for risk-engineering and public-policy studios. Students add their own country's code profile as coursework — and ship it upstream.

🤝 NGOs & community builders

Field teams get a printable checklist tuned to local hazards before they buy materials. Runs offline on a laptop or phone; no account, no fees, nothing uploaded.

Contribute — three ways, ten minutes each

  • Add your country's building code — run python tools/new_code_profile.py --id bd-bnbc --jurisdiction BD --name "Bangladesh National Building Code", fill the JSON, open a pull request. One file, fully validated by CI.
  • Correct a number we got wrong — every rule lives in plain JSON with citations. Fix it like a Wikipedia page; engineers worldwide benefit instantly.
  • Translate the interface — the website strings are being prepared for Bengali, Spanish and French contributions. Help a non-English-speaking municipality use it.
