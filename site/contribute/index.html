Get involved

Ten minutes, three ways — pick your difficulty

OpenShelter's fragile part (legal code text) is designed to be owned by many hands. You don't need to write Python to make a shelter safer.

EASY

Fix a number like Wikipedia

Every rule lives in plain JSON with citations. Spot a wrong threshold or missing clause? Edit the file, open a pull request, CI validates it. Non-coders can open an issue describing the fix and we'll pair with you.

Report a correction →
MEDIUM

Add your country's code

One command scaffolds a validated profile:
python tools/new_code_profile.py --id bd-bnbc --jurisdiction BD --name "Bangladesh National Building Code"
Fill the JSON with clause references, run the validator, submit. We review within days and credit you (or your agency) in the profile metadata.

Contributing guide →
ANY SIZE

Translate & teach

Bengali, Spanish and French first — help a non-English-speaking municipality use the tool. Or adopt the CLI in a risk-engineering studio: students shipping a real upstream code profile beats another toy assignment.

Start a discussion →
For institutions

Agencies, ministries & NGOs

  • Own your numbers. Publish your national flood/heat grids as a provider plugin — your scientists review the PR, your ministry gets named provenance in every brief.
  • Commission a profile. Fund the encoding of your building code (typically weeks of work, not months) and it stays open for every citizen forever.
  • Pilot a deployment. We're looking for 2–3 pilot municipalities to run real reconstruction briefs end-to-end and publish the results.

Good first issues

Where contributors usually start

  1. Harden the raster interface — wire the GEM Risk Library / Copernicus DEM providers into core/hazard.py (interface already exists).
  2. Profile clinics — pair with a standards engineer to encode BNBC (Bangladesh), NBC (Nepal), or Caribbean Uniform Building Code.
  3. PDF export — one clean print-ready template for briefs, requested by every pilot conversation so far.
  4. i18n strings — extract UI copy into JSON locales; Bengali translation is drafted and waiting.

Code of conduct: be kind, cite sources, assume good faith. AGPL keeps every contribution open — that's the deal, and it's why people contribute.
